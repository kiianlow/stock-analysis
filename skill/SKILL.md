# Stock analysis

Use when Kiian asks to analyse a ticker or company, or asks whether a stock is a buy, undervalued,
or worth selling a cash-secured put on.

1. Attach the GitHub repo `kiianlow/stock-analysis` to the session with push access (add_repo),
   then clone it to `/home/claude/stock-analysis`.
2. Read `CLAUDE.md` in the repo and follow it step by step. It is the single source of truth for
   data pulls, calculations, research, scoring, the report and saving.
3. If the repo cannot be attached, tell Kiian why and stop. Do not improvise a different workflow.
